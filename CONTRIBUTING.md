# Contributing to NeuroDock

Contributions are welcome.

## Steps

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes and test: `python3 run_pipeline.py`
4. Commit: `git commit -m "Add: your feature description"`
5. Push: `git push origin feature/your-feature`
6. Open a Pull Request

## Ideas for contributions

- Add new target proteins (MAO-A, AChE, BACE1, BuChE)
- Add MM-GBSA re-scoring after docking
- Add selectivity ratio calculation (MAO-B vs MAO-A)
- Add a Streamlit or Gradio web interface
- Add support for GNINA or Smina as alternative docking engines
- Improve interaction analysis with MDAnalysis
